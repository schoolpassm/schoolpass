2개 파일을 같은 경로에 덮어쓰기/추가하시면 됩니다.

- `components/institutions/InstitutionDashboardStats.tsx` (신규)

GitHub push → Vercel 자동배포. Firestore 변경 없음.

## 추가된 것

`/institutions` 목록 화면 맨 위에 지표 카드 12개 + 기관별 진행단계 분포 막대그래프가 붙습니다.

- 전체 기관 / 접촉 기관 / 진행 중 / 제품시연 / 시범사업검토 / 예산검토 / 계약완료 / 보류
- 금주 신규접촉 / 금주 후속조치 예정 / 후속조치 지연 (오늘 기준 다음접촉예정일이 지났는데
  아직 계약완료·보류·종료가 아닌 기관)
- 예상 계약금액 합계
- 기관별 진행단계 분포(16단계 막대그래프)

전부 이미 화면에서 불러오고 있는 institutions 목록을 그 자리에서 집계한 것이라, 기관
수가 400~500곳 정도로는 별도 쿼리나 인덱스 없이도 가볍게 동작합니다.

## 확인 사항

- `npx tsc --noEmit` 통과 확인 완료
- `/institutions` 열어서 카드 숫자들이 실제 데이터와 맞는지 눈으로 훑어보시면 됩니다
  (특히 "후속조치 지연"은 다음접촉예정일을 입력해둔 기관이 있어야 값이 나옵니다)
