## 추가된 것

교육지원청·교육청 상세페이지에만 "추천 학교" 패널이 새로 뜹니다 (그 외 관공서 유형에는
안 보입니다). 이 기관에 연결된 학교들(Phase 2에서 만드신 `eduOfficeId` 연결 기준) 중
아직 설치완료·계약·실패로 끝나지 않은 곳을 골라, 학생수와 기존 AI 계약가능성 점수 순으로
정렬해 상위 10곳을 보여줍니다.

**중요한 설계 판단**: 스펙 12번 끝에 "실제 데이터를 확인하지 않은 경우 추정값으로 표시하지
않는다"는 원칙이 있어서, 방문객 규모·수기 방문대장 여부·홈페이지 정보처럼 지금 CRM에
수집되지 않은 항목은 아예 화면에 안 씁니다 (지어내지 않음). 정렬도 AI를 호출해 매번 다른
설명을 만드는 대신, 코드로 투명하게 계산되는 규칙(AI 점수 → 학생수)만 씁니다 — 근거
없는 추천 문구가 나올 여지를 원천 차단하려는 선택입니다. 대신 실제로 갖고 있는 데이터
(학생수, AI 점수, 현재 영업단계, 같은 교육지원청 내 이미 도입/계약된 학교 수)는 전부
근거로 화면에 노출됩니다.

## 확인 사항

- `npx tsc --noEmit` 통과 확인 완료
- Phase 2에서 만든 교육지원청 하나(학교가 연결된 곳) 상세페이지 열어서 "추천 학교"
  패널이 뜨는지, 학생수·AI점수 순으로 정렬됐는지 확인
- 교육청(교육지원청의 상위) 하나도 열어서, 그 밑의 교육지원청들에 속한 학교들이
  전부 모여서 추천되는지 확인 — 단, Phase 2 마이그레이션은 학교↔교육지원청만
  연결했고 교육지원청↔교육청 상위 연결은 아직 안 하셨다면(Phase 3에서 폼으로
  수동 지정하신 경우에만 연결됨) 교육청 페이지에는 후보가 안 뜰 수 있습니다 —
  정상입니다.
