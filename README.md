## 이번에 추가된 것

1. **관공서 전용 16단계 파이프라인** (스펙 4번)
   - 조사 → 대상기관선정 → 담당부서확인 → 담당자확인 → 최초접촉 → 자료전달 → 미팅 →
     제품시연 → 시범사업검토 → 내부검토 → 예산검토 → 조달검토 → 계약협의 → 계약완료
     (+ 보류/종료)
   - `/institutions/kanban` 화면이 기존 9단계(학교와 공용이던 SchoolStatus) 대신
     이 16단계로 완전히 바뀝니다. **학교 칸반보드는 전혀 건드리지 않았습니다** — 별개
     컴포넌트라 안전합니다.
   - 기관 상세페이지 우측 상단 드롭다운도 16단계로 바뀝니다.
   - 기존 `status`(9단계) 필드는 데이터베이스에 그대로 남아있고 지우지 않습니다 — 새
     필드(`publicStage`, `stageEnteredAt`)를 추가로 쓰는 것뿐이라 기존 값·기존 화면
     어디에도 영향 없습니다. 한 번도 새 파이프라인을 쓴 적 없는 기관은 화면에서
     자동으로 "조사" 단계로 표시됩니다 (전체 기관에 일괄 쓰기를 하지 않아도 됨).

2. **14일 정체 알림** (스펙 4번 예시)
   - 어떤 기관이 현재 단계에 14일 이상 머물면:
     - 칸반 카드에 주황색 "N일째 정체" 배지
     - 칸반 상단에 "정체된 기관이 N곳 있습니다" 요약 배너
     - 기관 상세페이지 상단에도 같은 배지 표시
   - 계약완료/보류/종료 단계는 "정체"를 따지지 않습니다 (이미 끝났거나 보류 중이므로 의미 없음)

3. **AI 다음 액션 추천에 파이프라인 정보 반영** (스펙 9·10번과 연결)
   - AI 영업비서(전화스크립트/이메일/다음액션 등)에 전달되는 컨텍스트에 현재
     공공영업 파이프라인 단계, 그 단계에 머문 일수, 정체 여부가 추가됐습니다
   - 14일 이상 정체된 기관에 "다음 액션 추천"을 실행하면 AI가 정체 사실을 근거로
     언급하며 후속조치를 제안합니다 (기존 AI 패널 그대로 사용, 별도 버튼 안 만듦)

## 확인 사항

- `npx tsc --noEmit` 통과 확인 완료
- `/institutions/kanban` 열어서 16개 컬럼이 뜨는지, 카드 드래그가 여전히 되는지 확인
- 기관 하나 골라서 상세페이지에서 단계를 몇 번 바꿔보고, 시간을 되돌릴 수는 없으니
  정체 배지는 실제로 14일 지나야 확인 가능합니다 (기능 자체는 로직으로 검증 완료)
