학교 지오코딩 라우트와 동일한 패턴).

## 먼저 하셔야 하는 것 — 관공서 좌표 채우기

지금까지 관공서/교육행정기관(institutions)에는 좌표(위경도)를 채우는 경로가 아예
없었습니다. 이번에 관공서용 지오코딩 API와 **`/institutions` 화면의 "좌표 채우기
(지도용)" 버튼**을 같이 만들었으니, 적용 후 그 버튼을 한 번 눌러주세요 — 학교
지도의 "전체 자동 순회"와 똑같이 동작합니다(중단돼도 같은 버튼을 다시 누르면
이어서 진행). 좌표가 없으면 `/visit-planner` 지도에 관공서가 하나도 안 뜹니다.

## 추가된 것

1. **지도에 관공서/교육행정기관 표시** — 학교 지도(및 새로 만든 방문동선 화면)에
   보라색 다이아몬드 마커로 표시됩니다. 14일 이상 정체 중인 곳은 빨간 테두리로
   강조됩니다. 클릭하면 해당 기관 상세페이지가 새 탭으로 열립니다.

2. **`/visit-planner` 새 화면** (사이드바 "방문동선" 메뉴)
   - 학교(원형)+관공서(다이아몬드) 통합 지도
   - 오른쪽에 카테고리별 목록: 방문 예정 학교 / 재방문 필요 학교(14일+ 미접촉) /
     인근 교육지원청·교육청 / 방문 완료 학교 / 인근 학교(지도에 보이는 전체)
   - 체크박스로 오늘 방문할 곳을 고르고 "방문순서 제안" 클릭
   - **최근접이웃(Nearest Neighbor) 알고리즘**으로 순서를 계산합니다 — 브라우저 위치
     정보를 허용하면 현재 위치에서 가장 가까운 곳부터 시작, 거부하면 선택한 목록의
     첫 지점부터 시작합니다. 각 구간 거리(km)와 총 이동거리를 같이 보여줍니다.
   - 제안된 순서 그대로 "구글맵으로 열기" — 그 순서대로 경유지가 채워진 구글맵
     길찾기가 새 탭으로 열립니다 (실제 도로 경로·교통상황은 구글맵이 처리).

## 확인 사항

- `npx tsc --noEmit` 통과 확인 완료
- 관공서 좌표를 못 채운 상태에서는 지도에 다이아몬드 마커가 안 보이는 게 정상입니다
  (좌표 채우기 먼저 필요 — 위 안내 참고)
- 학교만으로도 체크박스 선택 → 방문순서 제안 → 구글맵 열기까지는 지금 바로 테스트
  가능합니다

## 이걸로 스펙 문서의 큰 항목(1~16번)은 전부 한 번씩 손이 갔습니다

정리하면:
- 1~3번(제품구조/계층/기본정보): Phase 1, 3
- 4번(파이프라인+정체알림): Phase 4
- 5번(예산CRM): 기존에 이미 있었음
- 6번(정책·공문CRM): Phase 3
- 7번(담당자CRM): Phase 3
- 8번(접촉기록): Phase 1(스키마) + 기존 화면
- 9·10번(AI 공공영업비서·다음액션): 기존 AI 패널 + Phase 4에서 파이프라인 정보 반영
- 11번(학교-교육행정기관 연결): Phase 2(마이그레이션) + Phase 3(계층 UI)
- 12번(추천학교): Phase 6
- 13번(대시보드): Phase 5
- 14번(지도 방문동선): Phase 7
- 15번(공통 CRM 엔진): 설계 원칙 자체를 Phase 1부터 계속 지킴 (institutions 컬렉션 하나로 통합)
- 16번(원칙): 전 구간에서 실제 CRM 데이터 근거·추측 금지 원칙 유지

실사용 테스트, 관공서 좌표 채우기, 그리고 기존에 미검증이라고 남겨두셨던 항목들
